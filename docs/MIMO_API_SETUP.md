# Xiaomi MiMo API Setup

The EI branch uses the real Xiaomi MiMo API model:

```text
Paper label: MiMo-V2.5
API model ID: mimo-v2.5
Token Plan base URL: https://token-plan-cn.xiaomimimo.com/v1
Endpoint: /chat/completions
Credential environment variable: MIMO_API_KEY
```

The repository does not track API keys. Put a newly rotated key in the local
project-root `.env` file:

```dotenv
MIMO_API_KEY=<your-rotated-key>
```

`load_config()` reads this file automatically. An explicitly defined process
environment variable takes precedence over the `.env` value.

Validate the endpoint with one minimal request:

```powershell
python -m scripts.probe_mimo --config configs/ei/llm_mimo.yaml
```

This probe prints the model response and non-secret audit metadata. It does not
write the credential to a file or manifest.

The submitted paper must identify the model as `MiMo-V2.5 (mimo-v2.5)`.
Results generated by MiMo must not be labelled as Qwen, GPT, GLM, or another
model family.

Configuration is stored in `configs/ei/llm_mimo.yaml`. The current
`fixtures/legacy_expert_cache.json` remains a synthetic smoke-test fixture and
is not paper evidence.

For formal experiments:

1. Generate state-conditioned expert responses through the real API with an
   explicit frozen Phase-2 environment configuration:

   ```powershell
   python -m scripts.generate_expert_cache `
     --env-config <frozen-phase2-config.yaml> `
     --num-samples 500
   ```

   The command writes both `artifacts/ei/expert_cache.json` and the matching
   `artifacts/ei/expert_scenario_bank.json`.
2. Save the raw response, state hash, prompt version, returned model, request
   ID, token usage, query latency, parser status, and parsed action.
3. Freeze the cache and share it across MiMo-V2.5 (LLM-only),
   MAPS-w/o-Annealing, and MAPS.
4. Report uncached API latency for MiMo-V2.5 and actor-only deployment latency
   for MAPS.

Credentials pasted into chats or committed to public repositories should be
treated as compromised. Revoke them in the provider console and use a newly
generated key locally.
